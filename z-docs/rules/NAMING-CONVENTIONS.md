If a file is autogenerated it must have .gen. in the name, e.g. `foo.gen.ts`

If a file is a test file it must have .test. in the name, e.g. `foo.test.ts`

If a file is a storybook file it must have .stories. in the name, e.g. `foo.stories.tsx`

If a file is a component it must be in PascalCase, e.g. `Foo.tsx`

If a file is a hook it must be in camelCase and start with use, e.g. `useFoo.ts`

If a file is a utility it must be in camelCase, e.g. `foo.ts`

If a file is a type definition it must be in PascalCase and end with .types, e.g. `Foo.types.ts`
