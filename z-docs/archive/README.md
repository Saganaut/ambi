# Archive

Deprecated / superseded docs that are kept around for history. Anything here is **not current** — read it as a snapshot of an earlier moment, not as guidance.

## In this folder

- [Claude review](claude-review.md) — A historical review pass over the codebase. Some observations are still accurate; treat the action items as out-of-date unless re-validated against current code.

## When to file something here

- A design doc whose plan landed and whose details are now better expressed in the code or a feature README.
- An old TODO list that has been replaced by something newer.
- An RFC that was rejected (but worth keeping for the reasoning).

If you're about to act on something in this folder, double-check the current state of the code first.
